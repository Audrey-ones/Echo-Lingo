# Echo-Lingo 产品使用说明书

## 1. 快速开始

### 1.1 首次使用
1. 打开 Echo-Lingo 网页
2. 选择分句灵敏度（可选，默认为"标准"）：
   - **精细**：适合语速慢、停顿清晰的音频，可自定义静音阈值和最小停顿时长
   - **标准**：适合大多数场景
   - **粗略**：适合语速快、停顿短的音频
3. 点击"选择音视频文件"上传一个英文音频或视频文件（支持 MP3 / MP4 / WAV / MOV 等）
4. 等待系统自动分析：解析媒体 → 分析停顿 → 自动翻译
5. 分析完成后显示检测到的句子数量，即可开始练习

### 1.2 支持的文件格式
| 类型 | 格式 |
|------|------|
| 音频 | MP3, WAV, OGG, M4A, FLAC, AAC |
| 视频 | MP4, WEBM, MOV, MKV, AVI, WMV |

### 1.3 备选导入方式
- **粘贴链接**：点击"或粘贴外部链接"，输入音视频直链 URL 加载
- **加载 JSON**：导入之前导出的课程 JSON 文件，恢复学习数据

## 2. 界面概览

```
┌──────────────────────────────────────────────┐
│  ← 返回  课程标题      [████░░] 3/15 [☀][听写|跟读] │  ← 顶栏
├──────────────────────────────────────────────┤
│  [1.0x] [循环]                                 │
│  ════════════════════════════════════════     │  ← 波形区
├──────────────────────────────────────────────┤
│                                              │
│              练习工作区                       │  ← 工作区
│                                              │
├──────────────────────────────────────────────┤
│  Space播放 /循环 ↑↓切换 ⇧+←→1.0x Enter提交 ... │  ← 底栏
└──────────────────────────────────────────────┘
```

- **顶栏**：返回按钮、课程标题、进度条、主题切换（☀/🌙）、听写/跟读模式切换
- **波形区**：音频波形可视化，彩色竖条标记句子边界，倍速和循环控制
- **工作区**：当前模式的练习界面
- **底栏**：键盘快捷键提示、导出按钮

### 2.1 主题切换
- 点击顶栏右侧的太阳/月亮图标切换浅色/深色主题
- 首次访问时自动跟随系统偏好
- 手动选择后偏好保存在浏览器中，下次访问自动应用

## 3. 听写模式

### 3.1 操作流程
1. 点击波形区或按 **Space** 开始播放
2. 在输入框中键入你听到的内容
3. 按 **Enter** 提交
4. 系统自动对比原文，完全正确（忽略标点大小写）→ 绿色闪烁并跳到下一句；有差异 → 显示逐词对比

### 3.2 对比结果解读
- **绿色下划线**：你多输入的词
- **红色删除线**：你漏掉或打错的词
- **灰色文字**：正确的部分
- 标点符号差异也会在对比中显示

### 3.3 句子导航
- 点击顶部编号药丸（pills）跳转到任意句子
- 当前句子自动滚动到视野中央
- 如果句子数过多，药丸行可左右滚动，两端显示渐变指示器
- 药丸颜色含义：
  - 🟣 紫色辉光 = 当前句子
  - 🟢 绿色 = 听写正确
  - 🔴 红色 = 听写错误
  - ⚫ 暗色 = 已完成（无记录）
  - ⬜ 浅色 = 未完成

### 3.4 编辑原文
- 鼠标悬停原文区域 → 点击右上角 ✏️ 图标
- 弹出 EditableField 组件：输入框 + ✓ 确认 + ✗ 取消
- Enter 保存，Esc 取消
- 如果句子没有设置原文，点击"设置本句英文原文"添加

### 3.5 撤销完成
- 提交正确的句子显示"✨ 已完成"标签
- 点击标签可撤销完成状态，重新听写

## 4. 跟读模式

### 4.1 操作流程
1. 查看英文原文和中文翻译
2. 点击 **原音** 播放原始音频，熟悉发音
3. 点击 **录制跟读** 开始用麦克风录制
4. 点击 **停止录制** 完成录音
5. 点击录音旁的 ▶ 播放录音自查
6. 点击 **同时播放**（🔊 图标）将原音和录音同步播放对比
7. 满意后点击 **标记已跟读** 或按 **Enter** 进入下一句

### 4.2 多录音对比
- 每次录制都会保留，最多保留 5 条录音
- 超出 5 条时自动移除最早的录音
- 录音列表最新在上，编号 #1, #2, #3...
- 超过 3 条时列表区内部滚动（不撑开页面）
- 点击 🗑️ 删除不需要的录音
- 切换到其他句子再切回来，录音仍在

### 4.3 编辑原文和翻译
- 点击原文或翻译旁的 ✏️ 图标进入编辑模式（使用 EditableField 组件）
- Enter 保存 / Esc 取消
- 编辑英文原文后，如果没有中文翻译则自动触发翻译

### 4.4 注意事项
- 切换模式（听写↔跟读）会清除所有录音，请提前导出
- 浏览器需要授权麦克风权限
- 录音仅在当前会话内有效，刷新页面后丢失

## 5. 键盘快捷键

| 按键 | 功能 | 说明 |
|------|------|------|
| **Space** | 播放/暂停 | 当前句子内暂停后按 Space 从暂停位继续；跳到句首需等播放完再按 |
| **↑** | 上一句 | 自动播放上一句 |
| **↓** | 下一句 | 自动播放下一句 |
| **Enter** | 提交/完成 | 听写模式提交答案；跟读模式标记完成 |
| **/** | 循环开关 | 开启后当前句子反复播放 |
| **Shift + ←** | 减速 | 每次 -0.1x，最低 0.5x |
| **Shift + →** | 加速 | 每次 +0.1x，最高 2.0x |
| **Tab** | 翻译 | 按住显示翻译浮层，松开隐藏 |

> 注意：在输入框（听写、编辑）内时，除 Enter 和 Esc 外的大部分快捷键会被禁用以免干扰输入。

## 6. 导出与备份

### 6.1 导出 JSON
- 加载课程后，底栏"导出"按钮可用
- 点击保存课程数据为 JSON 文件
- JSON 包含：句子文本、时间戳、中英双语翻译、课程元数据
- 建议分析完成后立即导出备份

### 6.2 导入 JSON
- 在首页点击"加载已有 JSON 课程"恢复之前的课程
- 注意：JSON 导入仅恢复课程结构（含翻译），不含音频文件和练习进度

## 7. 常见问题

**Q: 上传文件后一直显示"正在分析..."？**
A: 大文件处理时间较长，视频文件需要提取音频。请耐心等待，通常 1 分钟内完成。

**Q: 句子切分不准确怎么办？**
A: 上传前先选择灵敏度。精细模式可调整静音阈值（0.02~0.12）和最小停顿时长（0.1s~0.8s）以获得更准确的分句。

**Q: 翻译不显示或不准确？**
A: 翻译通过 MyMemory 免费 API（优先）和 Google Translate 作为备选。如两者均失败可手动编辑中文翻译。

**Q: 关闭浏览器后进度还在吗？**
A: 完成状态会自动保存到浏览器本地存储（IndexedDB），重新打开页面后自动恢复。录音和听写记录不保存。

**Q: 为什么粘贴的链接加载失败？**
A: 仅支持以 .mp3/.mp4 等结尾的直链。B 站/YouTube 等平台链接需先用 `yt-dlp` 等工具下载后上传。

**Q: 如何切换到浅色模式？**
A: 点击顶栏右侧的太阳图标。主题偏好会自动保存，下次访问时保持。

**Q: 录音数量有上限吗？**
A: 每个句子最多保留 5 条录音，超出后自动移除最早的录音。
