# Echo-Lingo 开发过程记录

## 项目概述

Echo-Lingo 是一款本地优先的英语听力/口语练习工具，基于 Next.js 16 + React 19 + Tailwind CSS 4 + WaveSurfer.js 7.12.6 + Zustand 5 + Dexie.js 4 构建。支持浅色（Dusty Rose）和深色主题。

---

## 一、初始状态（接手时）

项目已具备基础框架：
- 音视频上传与自动分句（基于 RMS 静音检测）
- 听写模式基本功能（输入、diff 对比、完成标记）
- 跟读模式占位符
- IndexedDB 进度持久化（单完成列表）
- WaveSurfer 音频波形可视化
- 仅支持深色模式

## 二、第一轮：存储分析与项目审计

### 2.1 存储空间分析
- **用户反馈**：项目占用 974MB 存储空间
- **分析结果**：505MB `.next`（构建缓存）+ 424MB `node_modules`（依赖）
- **结论**：`.next` 可安全清理（`next clean`），下次构建会重新生成；`node_modules` 不可跨项目共享
- **后续讨论**：解释了 Next.js 的作用、依赖管理方式（推荐每个项目独立 `node_modules`）、定期清理策略

### 2.2 首次全系统审计
对系统进行了全面检查，识别出以下问题：

| # | 问题 | 严重度 |
|---|------|--------|
| 1 | 翻译功能无重试机制，单句串行慢 | 中 |
| 2 | 原音+录音同时播放（playBoth）不同步 | 高 |
| 3 | 听写模式 Footer 显示无意义的按键提示 | 低 |
| 4 | 导出按钮在未加载课程时仍可点击 | 低 |
| 5 | 编辑参考文本 UI 在听写和跟读中重复实现 | 低 |
| 6 | 噪声纹理 z-index 过高（9999） | 低 |
| 7 | 句子编号 pills 行无溢出滚动指示器 | 低 |

## 三、第一轮修复（7项）

### 3.1 翻译功能增强 (`src/lib/translate.ts`)
- 新增 `fetchWithRetry()` 函数：2 次重试，1s/3s 指数退避
- `translateSentences()` 改为 3 句并发批量，200ms 批间延迟
- 跳过已有 en 或已有 zh 的句子

### 3.2 底栏改进 (`src/components/layout/footer-bar.tsx`)
- 新增 `mode` prop：听写模式显示"Enter 提交听写"，跟读模式显示"Enter 标记完成"
- 导出按钮增加 `disabled={!lesson}` 状态和禁用样式

### 3.3 共享编辑组件 (`src/components/shared/editable-field.tsx`)
- 从听写和跟读工作区中提取重复的编辑 UI 为 EditableField 组件
- Enter 保存、Esc 取消、autoFocus、placeholder 配置
- 绿色确认按钮 + 灰色取消按钮

### 3.4 噪声纹理 z-index 修复 (`src/app/globals.css`)
- z-index: 9999 → 1，避免遮挡弹窗和交互元素

### 3.5 Pills 滚动指示器
- 听写和跟读工作区中添加溢出检测（scrollWidth > clientWidth）
- 左右渐变遮罩使用 `color-mix(in srgb, var(--color-zinc-950) 70%, transparent)` 确保主题安全
- resize 和 scroll 事件监听自动更新显示状态

### 3.6 playBoth 同步修复尝试 → 最终回退
- **第一次尝试**：改为顺序播放（先录音后原音）→ 用户不满意："我要同时播放"
- **第二次尝试**：静音修剪录音开头 → 用户反馈"好像没起作用"
- **第三次尝试**：基于语音起始检测（onset detection）对齐 → 用户反馈"还是不行，有延迟"
- **最终**：用户要求完全恢复原始同时播放行为。三版改动全部回退。

### 3.7 用户反馈要点
- "我要的功能是像之前一样的功能，跟读模式的 playBoth 功能同时播放原声和录音"
- "原音和录音的声音是对齐的。比如说，我是什么时候开始说话，原音也应当是什么时候开始说话"
- "要考虑到录音先放出声音后，隔了一段时间原音才开始有声音"
- "算了，不改了，给我恢复成最原始的跟读模式的 playBoth 功能"

## 五、第二轮修复（4项）

### 5.1 Progress 写入竞态修复 (`src/stores/lesson-store.ts`)
- `markCompleted()` 和 `unmarkCompleted()` 在 `set()` 后立即调用 `get()` 读取最新 state
- 再用最新值构建 progress 对象写入 IndexedDB
- 解决了快速连续操作时 state 快照过期的问题

### 5.2 timeupdateSyncRef 竞态修复
- **`src/app/page.tsx`**：regions 的 `region-clicked` 回调中先重置 `timeupdateSyncRef.current = false` 再调用 `setCurrentIndex`
- **`src/hooks/use-keyboard.ts`**：ArrowDown/ArrowUp 先调用 `window.__echoResetTimeupdateFlag?.()` 再导航
- 避免 timeupdate 触发的自动导航与用户手动导航冲突

### 5.3 DB 迁移确认 (`src/lib/db.ts`)
- 经验证 v1→v2 的 `.upgrade()` 迁移已正确实现
- 旧 `completed_sentences` 正确复制到 `completed_dictation` 和 `completed_shadowing`

### 5.4 录音数量限制 (`src/components/shadowing/shadowing-workspace.tsx`)
- 每句最多保留 5 条录音
- 超出时自动移除最早的录音并 `URL.revokeObjectURL()` 释放 Blob URL
- 防止内存泄漏

## 六、第三轮修复（3项）

### 6.1 翻译覆盖用户编辑修复 (`src/components/layout/file-uploader.tsx`) 【CRITICAL】
- **问题**：文件上传和 JSON 导入后的翻译回调使用闭包捕获的旧 lesson 对象
- **后果**：用户在翻译完成前手动编辑的 zh/en 被覆盖
- **修复**：回调中使用 `useLessonStore.getState().lesson` 获取最新 store 状态
- 使用 `s.zh || translations[i]` 仅在无现有翻译时才填充

### 6.2 渐变遮罩主题安全 (`src/components/dictation/dictation-workspace.tsx`)
- pills 滚动渐变指示器从 CSS class 改为 inline style
- 使用 `color-mix(in srgb, var(--color-zinc-950) 70%, transparent)`
- 确保在浅色/深色模式下渐变颜色都正确

### 6.3 听写 diff 标点可见 (`src/components/dictation/dictation-workspace.tsx`)
- **问题**：`diffWords` 在 `clean()` 后的文本上运行，标点差异不可见
- **修复**：`diffWords(s.en, input.trim())` 直接在原始文本上对比
- 标点符号错误现在在 diff 结果中可见

## 七、浅色/深色主题实现

### 7.1 方案设计
- 利用 Tailwind CSS v4 的 `@custom-variant dark` + `@layer theme` 能力
- 所有组件使用语义化 `bg-zinc-*` / `text-zinc-*` 无需修改
- 浅色模式采用 Dusty Rose 暖色调，深色保持原有配色
- 无 `.dark` class = 浅色（新默认），有 `.dark` = 深色

### 7.2 实施

**`src/app/globals.css`**：
- 添加 `@custom-variant dark (&:where(.dark, .dark *))`
- `@theme` 中定义 Dusty Rose 浅色色值（#fbf7f7 ~ #241a1a）
- `@layer theme { :root, :host { @variant dark { /* 深色覆盖 */ } } }` 中保留原深色色值
- 噪点纹理改为 `.dark body::before`（仅深色模式）
- 滚动条颜色使用 CSS 变量引用

**`src/app/layout.tsx`**：
- `<head>` 中添加内联 `<script>`：页面渲染前读取 `localStorage['echo-theme']` 和系统偏好
- 提前给 `<html>` 添加 `.dark` class 防止页面闪烁（FOUC）

**`src/components/layout/top-bar.tsx`**：
- 新增 Sun/Moon 图标切换按钮
- `toggleTheme()`：切换 `.dark` class + 写入 localStorage
- 监听 `prefers-color-scheme` 变化（未手动设置时跟随系统）
