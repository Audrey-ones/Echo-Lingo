## 3. 架构设计

### 3.1 数据流

```
用户上传文件
    │
    ▼
extractAudioBuffer()          ← audio-analyzer.ts
    │  解析媒体 → AudioBuffer + BlobURL
    ▼
analyzeAudio() / analyzeAudioFine()  ← audio-analyzer.ts
    │  静音检测 → 切分句子 [{id, start_time, end_time}]
    ▼
setLesson()                   ← lesson-store.ts
    │  写入 Zustand store + 触发 loadProgress()
    ▼
translateSentences()          ← translate.ts
    │  跳过已有翻译的句子，3句一批并发翻译（200ms 批间延迟）
    │  回调中读取 getState().lesson（避免闭包过期）
    ▼
updateLesson()                ← lesson-store.ts
    │  更新翻译结果（zh 字段），不重置 currentIndex
    ▼
WaveSurfer渲染 + 练习交互
    │  ┌─ 听写: handleSubmit() → clean() → diffWords() → addDictationRecord() → markCompleted()
    │  └─ 跟读: MediaRecorder → Recording[] → WaveSurfer实例 → markCompleted()
    ▼
markCompleted() / unmarkCompleted()  ← lesson-store.ts
    │  set() 更新内存 → get() 读取最新 → db.progress.put() 写入 IndexedDB
    ▼
刷新页面时 loadProgress() 从 IndexedDB 恢复完成状态
```

### 3.2 组件通信

```
page.tsx (顶层编排)
    │  mode state: "dictation" | "shadowing"
    │  timeupdateSyncRef: 自动播放同步标记
    │  lastLoadedUrlRef: WaveSurfer 重复初始化守卫
    │
    ├─ TopBar ← props: mode, onModeChange, onBack, completed, total
    │      │     内部: isDark state + toggleTheme()
    │
    ├─ WaveSurfer 实例 (page.tsx 内部 useEffect)
    │      │     regions: 彩色区域标记句子边界
    │      │     region-clicked → 重置 timeupdateSyncRef → setCurrentIndex
    │      └─ window.__echoWavesurfer (全局暴露供 use-keyboard 访问)
    │         window.__echoPlayCurrentSentence
    │         window.__echoMarkInteracted
    │         window.__echoResetTimeupdateFlag
    │
    ├─ DictationWorkspace / ShadowingWorkspace
    │      │     直接读取 useLessonStore()
    │      │     EditableField 共享编辑组件
    │
    ├─ FooterBar ← mode prop（显示对应快捷键提示）
    │
    └─ useKeyboard() ← 通过 window.__echo* 全局变量控制播放
           │  ArrowUp/Down → 重置 timeupdateSyncRef → 导航
           │  visibilitychange → 重置 Tab 状态
```

## 4. 核心模块详解

### 4.1 浅色/深色主题 (`globals.css` + `layout.tsx` + `top-bar.tsx`)

#### CSS 变量策略
```css
@custom-variant dark (&:where(.dark, .dark *));

@theme {
  /* 默认 = 浅色 Dusty Rose */
  --color-zinc-950: #fbf7f7;
  /* ... */
}

@layer theme {
  :root, :host {
    @variant dark {
      /* 覆盖为深色值 */
      --color-zinc-950: #050508;
      /* ... */
    }
  }
}
```
- 所有组件使用语义化 `bg-zinc-*` / `text-zinc-*` 类，自动跟随主题切换
- 噪点纹理仅深色模式：`.dark body::before { opacity: 0.018; }`
- pills 滚动渐变使用 inline style + `color-mix(in srgb, var(--color-zinc-950) 70%, transparent)` 实现主题安全

#### 防闪烁 (FOUC Prevention)
`layout.tsx` 中内联 `<script>`，在 React 水合前执行：
```javascript
(function(){
  var t = localStorage.getItem('echo-theme');
  if (t === 'dark' || (!t && matchMedia('(prefers-color-scheme:dark)').matches)) {
    document.documentElement.classList.add('dark');
  }
})()
```

#### 切换逻辑
- 点击 TopBar 按钮 → `classList.toggle('dark')` → 写入 `localStorage['echo-theme']`
- 未手动设置时，监听 `prefers-color-scheme` 变化自动跟随系统

### 4.2 音频分析 (`audio-analyzer.ts`)

#### 文件提取
```typescript
extractAudioBuffer(source: File | string): Promise<AudioExtractResult>
```
- 文件：FileReader → ArrayBuffer → AudioContext.decodeAudioData
- URL：fetch CORS → ArrayBuffer → decodeAudioData
- 视频：`<video>` 元素播放 → MediaRecorder 录制音频轨道 → decodeAudioData

#### 静音检测算法（标准模式）
```
参数：
  silenceThreshold = 0.05   // RMS 音量阈值
  minSilenceDuration = 0.6s  // 最小停顿时长
  minSentenceDuration = 0.8s // 最小句子时长
  padding = 0.05s            // 句子边界前后留白

流程：
1. 计算整个音频的 RMS (Root Mean Square) 音量
2. 逐样本遍历：音量 < 阈值 → 静音区域
3. 合并相邻静音区域
4. 相邻静音区之间的非静音区域 = 句子
5. 过滤太短的句子 (< minSentenceDuration)
6. 为每个句子边界添加 padding
```

#### 精细模式 (`analyzeAudioFine`)
- 用户可自定义 `silenceThreshold` (0.02~0.12) 和 `minSilenceDuration` (0.1s~0.8s)
- 粗略模式：`silenceThreshold=0.03, minSilenceDuration=1.0, minSentenceDuration=0.5`

#### AudioContext 泄漏修复
- `decodeCtx` 在 catch 分支中调用 `.close()` 释放资源

### 4.3 状态管理 (`lesson-store.ts`)

```typescript
interface LessonState {
  lesson: LessonData | null;
  audioBlobUrl: string | null;
  currentIndex: number;
  playbackRate: number;        // 0.5 ~ 2.0
  isLooping: boolean;
  showTranslation: boolean;
  completedInDictation: string[];   // 听写完成列表
  completedInShadowing: string[];   // 跟读完成列表
  dictationRecords: Record<string, DictationRecord>;  // 听写记录（仅内存）
}
```

#### 关键方法
| 方法 | 说明 |
|------|------|
| `setLesson(data)` | 设置课程，重置 currentIndex=0 和 dictationRecords={}，触发 loadProgress() |
| `updateLesson(data)` | 仅更新课程数据，不重置索引和记录（翻译保存用） |
| `markCompleted(id, mode)` | set() 更新 → get() 读取最新 → db.progress.put() 写入 |
| `unmarkCompleted(id, mode)` | 从完成列表移除，删除对应 dictationRecord，写入 IndexedDB |
| `adjustPlaybackRate(delta)` | ±0.1 步进，限制 [0.5, 2.0] |

#### 竞态条件修复
`markCompleted` 和 `unmarkCompleted` 在 `set()` 后立即调用 `get()` 获取最新 state，而非直接使用闭包中捕获的值，确保 DB 写入的是最新完成列表。

### 4.4 翻译服务 (`translate.ts`)

```typescript
// 重试包装
fetchWithRetry(url, retries=2): Promise<Response | null>
  → 429/5xx 或网络错误 → 等待 1s/3s → 重试

// 单句翻译
translateOne(text: string): Promise<string>
  → MyMemory API (免费，5000字/天)
  → Google Translate (非官方端点)
  → 均失败返回 ""

// 批量翻译
translateSentences(sentences): Promise<{ [index]: number]: string }>
  → 跳过已有 en 和已有 zh 的句子
  → 3句一批并发（Promise.all）
  → 200ms 批间延迟
  → 返回 index → translation 映射
```

#### 翻译覆盖用户编辑修复
`file-uploader.tsx` 中翻译回调使用 `useLessonStore.getState().lesson` 获取当前 lesson，而非闭包中捕获的旧引用。使用 `s.zh || translations[i]` 仅在无现有翻译时才填充新翻译。

### 4.5 听写对比 (`dictation-workspace.tsx`)

```typescript
// 对比流程
1. 无 en → 直接通过，"no-reference"
2. clean(userInput) vs clean(s.en)
```

## 6. 已知限制与待解决问题

| 限制 | 优先级 | 说明 |
|------|--------|------|
| 听写记录不持久化 | 中 | dictationRecords 仅内存，刷新丢失，需 DB v3 迁移 |
| 录音不持久化 | 中 | Blob 存 IndexedDB 数据量大，仅会话内有效 |
| window.__echo* 全局耦合 | 中 | WaveSurfer 实例通过全局变量在组件间共享，需 React Context 重构 |
| 翻译服务国内可能被墙 | 中 | Google Translate 非官方端点在境内可能不可用 |
| 返回按钮整页刷新 | 低 | 应改为路由跳转 + 软重置 |
| Tab 键被劫持 | 低 | 翻译功能占用 Tab，破坏键盘无障碍导航 |
| 音频切句尾音截断 | 低 | 静音检测可能将软辅音结尾误判为静音 |
| DB 键名不一致 | 低 | lesson_id vs id 命名不统一 |
| Blob URL 跨导航累积 | 低 | 多次切换句子可能累积未释放的 Blob URL |
| 无移动端适配 | 低 | 设计以桌面端为目标 |
| 无文件大小校验 | 低 | 超大文件可能导致浏览器内存溢出 |
