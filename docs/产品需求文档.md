# Echo-Lingo 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品愿景
Echo-Lingo 是一款本地优先的英语听力与口语练习工具。用户上传音视频文件或粘贴链接，系统自动切分句子，支持听写和跟读两种练习模式。支持浅色（Dusty Rose）和深色两种主题。

### 1.2 目标用户
- 英语学习者，希望提升听力和口语能力
- 偏好本地化工具、注重数据隐私的用户
- 使用自定义学习素材（播客、视频、音频课程）的用户

### 1.3 核心价值
- **本地优先**：所有处理在浏览器完成，数据存储于 IndexedDB，无需后端服务器
- **自动切句**：基于静音检测自动将音频切分为句子，无需手动标注
- **双模式练习**：听写模式训练听力理解，跟读模式训练口语发音
- **主题切换**：支持浅色/深色主题，首次自动跟随系统偏好

## 2. 功能需求

### 2.1 音视频导入

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 本地上传 | 支持 MP3/WAV/OGG/M4A/FLAC/AAC（音频）和 MP4/WEBM/MOV/MKV/AVI/WMV（视频） | P0 |
| URL 加载 | 粘贴音视频直链加载媒体文件 | P1 |
| JSON 导入 | 加载已导出的课程 JSON 文件恢复学习数据 | P1 |
| 分句灵敏度 | 精细/标准/粗略三档，精细模式支持自定义静音阈值和最小停顿时长 | P1 |

### 2.2 音频处理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 静音检测 | 基于 RMS 音量阈值自动检测停顿，将音频切分为句子 | P0 |
| 视频音频提取 | 从视频文件中提取音频轨道 | P1 |
| 自动翻译 | 将英文句子翻译为中文（MyMemory + Google 双引擎，重试+并发批处理） | P1 |

### 2.3 听写模式

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 句子导航 | 编号药丸（pills）展示所有句子，颜色标识状态（当前/正确/错误/已完成），溢出时显示渐变滚动指示器 | P0 |
| 听写输入 | 大字号等宽字体输入区，用户输入听到的内容 | P0 |
| 对比纠错 | 提交后在原文上进行逐词 diff 对比，绿色下划线=多余、红色删除线=缺失，标点符号差异可见 | P0 |
| 原文编辑 | 使用 EditableField 组件编辑英文原文，Enter 保存、Esc 取消 | P1 |
| 翻译编辑 | 编辑英文原文后自动触发翻译（如无现有翻译） | P2 |
| 完成标记 | 提交正确后自动标记完成并跳到下一句（400ms 延迟） | P0 |
| 撤销完成 | 点击已完成标签可撤销，重新听写，同时清除该句 dictationRecord | P1 |
| 无原文模式 | 未设置原文的句子接受任意输入为完成，显示琥珀色提示标签 | P1 |

### 2.4 跟读模式

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 原文展示 | 大字号展示英文原文，附带中文翻译 | P0 |
| EditableField | 统一的编辑组件，用于编辑英文原文和中文翻译 | P0 |
| 录音功能 | 使用麦克风录制用户跟读音频（audio/webm） | P0 |
| 多录音支持 | 同一句子最多保留 5 条录音，超出自动移除最早的并释放 Blob URL | P1 |
| 录音回放 | 每条录音独立 WaveSurfer 波形展示，支持播放/删除 | P0 |
| 原音播放 | 播放原始音频作为参考 | P0 |
| 同步播放 | 同时播放原音和用户录音进行对比（playBoth） | P1 |
| 完成标记 | 手动标记句子为已跟读，自动跳到下一句（400ms 延迟） | P0 |

### 2.5 通用功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 波形可视化 | WaveSurfer 渲染音频波形，彩色区域标记句子边界 | P0 |
| 浅色/深色主题 | 顶栏 Sun/Moon 按钮切换，首次默认跟随系统，偏好存 localStorage | P0 |
| 防闪烁加载 | 内联 `<script>` 在页面渲染前读取主题偏好，避免 FOUC | P0 |
| 键盘快捷键 | Space 播放/暂停、↑↓ 切换句子、Shift+←→ 调速、/ 循环、Enter 提交 | P0 |
| 循环播放 | 单句循环模式，反复听同一句子 | P1 |
| 变速播放 | 0.5x ~ 2.0x 范围，0.1 步进 | P1 |
| 进度持久化 | 两种模式完成状态独立存储到 IndexedDB，刷新不丢失 | P0 |
| 进度写入防竞态 | markCompleted/unmarkCompleted 在 DB 写入前读取最新 state 避免闭包过期 | P0 |
| 导航同步 | 用户手动导航（pills 点击、箭头键）重置自动播放同步标记 | P0 |
| JSON 导出 | 导出课程数据（含句子、时间戳、翻译）为 JSON 文件 | P1 |
| 模式切换 | 听写/跟读模式一键切换，进度独立跟踪 | P0 |

## 3. 非功能需求

### 3.1 性能
- 音频分析应在 30 秒内完成（< 10 分钟音频）
- 页面首屏加载 < 3 秒
- 录音延迟 < 100ms
- 翻译 3 句并发批量，200ms 批间延迟

### 3.2 兼容性
- 支持 Chrome 90+、Edge 90+、Firefox 100+、Safari 16+
- 需支持 Web Audio API 和 MediaRecorder API

### 3.3 安全性
- 所有处理完全在本地浏览器进行
- 音视频文件不上传到任何服务器
- 翻译请求通过第三方免费 API（MyMemory / Google Translate）

### 3.4 可维护性
- 组件化架构，单一职责
- TypeScript 全量类型覆盖
- 状态管理集中化（Zustand + IndexedDB）
- 共享 UI 组件抽取（EditableField）

## 4. 用户故事

1. 作为一个英语学习者，我希望能上传自己喜欢的播客音频，自动切分成句子逐个练习听写
2. 作为一个口语练习者，我希望录制自己的跟读并与原音对比，发现发音差异
3. 作为一个长期学习者，我希望我的练习进度能自动保存，下次打开继续学习
4. 作为一个进阶用户，我希望导出带有时间戳的课程数据，分享给其他学习者
5. 作为一个夜间学习的用户，我希望在深色模式下练习以保护眼睛

## 5. 已知限制

| 限制 | 说明 |
|------|------|
| 听写记录不持久化 | dictationRecords 仅内存存储，刷新页面丢失 |
| 录音不持久化 | 仅会话内有效，切换模式清除 |
| 返回按钮全页刷新 | 未做软重置，点击返回执行整页重载 |
| Tab 键被劫持 | 翻译功能占用 Tab，破坏键盘无障碍导航 |
| 全局变量耦合 | window.__echo* 属性在组件间传递 WaveSurfer 实例 |
| 无参考句任意通过 | 未设置 en 的句子接受任意输入即标记完成 |
| 空翻译覆盖 | 空 zh 保存可能覆盖已有翻译 |
| DB 键名不一致 | lesson_id vs id 命名不统一 |
